| **Factor**                    | **Short Definition**                                             | **Example**                                                                                    |
| ----------------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Appearance/Attractiveness     | Visually appealing and aesthetically pleasing.                   | A elegant, modern UI design with consistent colors and layout.                                 |
| Completeness                  | Offers all necessary information and functions.                  | A task manager that includes calendar sync, notifications, and attachments.                    |
| Controllability/Dependability | Responds consistently and predictably to user actions.           | Buttons always perform the expected action without delay. And if delayed user will be informed |
| Convenience                   | Makes tasks or life easier for the user. Has necessary features. | Autofill for login credentials.                                                                |
| Craftsmanship                 | High build quality; feels solid and well-made.                   | An app that doesn’t crash and has polished UI transitions.                                     |
| Ease of use                   | Simple and straightforward to operate.                           | A one-click checkout process.                                                                  |
| Efficiency                    | Achieves goals with minimal effort or time.                      | Good visible navbar to navigate trough app, by a single click.                                 |
| Emotion/Affect                | Evokes emotional responses.                                      | A calming background animation that makes users feel relaxed.                                  |
| Flexibility                   | Can be customized for different needs or styles.                 | Dashboard widgets that users can rearrange.                                                    |
| Fun                           | Enjoyable and playful to use.                                    | A to-do list app that celebrates completed tasks with animations.                              |
| Helpfulness                   | Provides support and guidance to the user.                       | In-app tooltips and onboarding tutorials.                                                      |
| Identity                      | User relates to the product personally.                          | A profile page that reflects user interests or styles.                                         |
| Immersion                     | Absorbs the user fully, making them lose track of time.          | A deeply engaging game or interactive story app.                                               |
| Intuitive Operation           | Instantly usable without instructions.                           | Drag-and-drop file upload without prior explanation.                                           |
| Learnability/Perspicuity      | Easy to learn and understand quickly.                            | Clear menu labels and onboarding hints.                                                        |
| Loyalty                       | Promotes repeat use and positive word-of-mouth.                  | A productivity app users recommend and use daily.                                              |
| Novelty                       | Feels fresh, new or different.                                   | A creative journaling app with unique writing prompts.                                         |
| Originality                   | Designed in a distinctive or unusual way.                        | A uniquely themed interface like dark-mode neon for a coding app.                              |
| Overall                       | General impression of quality and satisfaction.                  | A five-star app store rating with glowing user reviews.                                        |
| Relevancy                     | Information is meaningful and significant to the user.           | Personalized news feed or content suggestions.                                                 |
| Pragmatic Quality             | Functional and useful in practice.                               | A note-taking app that syncs across all devices.                                               |
| Simplicity                    | Minimal complexity in operation.                                 | A single search bar that handles all queries.                                                  |
| Social Influences             | Supports social interaction or image.                            | Shareable fitness achievements in a workout app.                                               |
| Stimulation                   | Encourages continued engagement and exploration.                 | Unlockable features or gamification elements.                                                  |
| Trust/Credibility             | Appears secure and reliable.                                     | Two-factor authentication and clear privacy policy.                                            |
